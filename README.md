
# Employee Attrition Analyzer
## 📌 Project Overview
The **Employee Attrition Analyzer** is a Machine Learning project that predicts whether an employee is likely to leave a company.
The project uses the **IBM HR Analytics Employee Attrition & Performance dataset** and applies three classification models:
- Logistic Regression
- Decision Tree
- Random Forest

The models are compared using classification metrics and confusion matrices.

---

##  Objective

The main objective of this project is to:
- Clean and preprocess employee data
- Handle categorical and numerical features
- Predict employee attrition
- Compare different Machine Learning models
- Evaluate model performance
- Identify important features affecting employee attrition

##  Dataset

**Dataset:** IBM HR Analytics Employee Attrition & Performance

 Target Variable

`Attrition`

- `Yes` → Employee left the company
- `No` → Employee stayed in the company

For Machine Learning:

- `Yes` → `1`
- `No` → `0`
